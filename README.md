# Banko Chow

Street food with a classy twist. One codebase that ships as a **website / web app**, an **iOS app** and an **Android app**.

- Street Burgers on Agege bread (Mainland · Island · Linkbridge), zobo with zero added sugar, extras
- Ordering flow: build a bag, choose pickup or delivery, send the order to the Banko Chow WhatsApp line
- Brand story, photo gallery, Find Us with map, call and Instagram links
- Frosted-glass UI (translucent containers and pill buttons) over the brand orange backdrop
- Mobile: bottom glass tab bar, safe-area aware, haptics, Android back button, splash + status bar styling

## Stack

| Layer | Choice |
| --- | --- |
| Web | [Vite](https://vite.dev) + React 19 + TypeScript + Tailwind CSS v4 |
| Routing | `react-router` v7 (`/`, `/menu`, `/order`, `/story`, `/gallery`, `/find-us`) |
| Native shells | [Capacitor 8](https://capacitorjs.com) (`ios/`, `android/`) with `@capacitor/app`, `status-bar`, `splash-screen`, `haptics` |
| Fonts | Fredoka (display) + Outfit (body), self-hosted via `@fontsource-variable` so the apps work offline |

iOS and Android parity comes for free: both apps render the exact same bundle in a native web view, with
the native layer only handling the splash screen, status bar, safe areas, haptics and the hardware back button.

## Project layout

```
src/
  config/site.ts        business details (phone, WhatsApp, address, Instagram, slang) — edit here
  data/menu.ts          menu items, prices, extras, "coming soon" items — edit here
  components/ui/        Glass, GlassButton, Sheet, Badge, QuantityStepper …
  components/layout/    AppShell (header + tab bar), Footer, Page helpers
  components/menu/      MenuItemCard, ItemSheet (extras + quantity picker)
  pages/                Home, Menu, Order, Story, Gallery, FindUs, NotFound
  store/                cart state (persisted to localStorage)
  lib/                  formatting, WhatsApp order message, Capacitor helpers
  assets/               optimised brand photography + logos
assets/                 source icon/splash artwork for `npm run cap:assets`
android/, ios/          native projects (generated by Capacitor, committed)
```

## Getting started

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production bundle in dist/
npm run preview      # serve dist/ locally
npm run lint         # oxlint
```

Requirements: Node 22+.

## Updating content

- **Menu & prices** — `src/data/menu.ts`
- **Phone / WhatsApp / address / Instagram / hours** — `src/config/site.ts`
- **Photos** — drop optimised `.webp` files into `src/assets/images/` and register them in `src/assets/images/index.ts`

Orders are sent as a pre-filled WhatsApp message to the number in `site.whatsapp`. No backend is required.

## Website deployment

`npm run build` produces a static site in `dist/`. Deploy it to any static host (Vercel, Netlify, Cloudflare Pages,
GitHub Pages). The app uses client-side routing, so configure a SPA fallback to `index.html`
(`public/_redirects` covers Netlify; `vercel.json` covers Vercel). If the site lives under a sub-path, build with
`VITE_BASE=/sub-path/ npm run build`.

## iOS

Requirements: macOS, Xcode 16+, Node 22+. Capacitor 8 uses Swift Package Manager, so no CocoaPods is needed.

```bash
npm run ios                 # builds the web bundle, syncs it into ios/, opens Xcode
```

In Xcode select the `App` target → Signing & Capabilities → pick your Team, then run on a simulator or device.
Archive with Product → Archive to upload to TestFlight / the App Store.

Command-line simulator build (what CI does):

```bash
npm run cap:sync
xcodebuild -project ios/App/App.xcodeproj -scheme App -sdk iphonesimulator \
  -configuration Debug -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO build
```

## Android

Requirements: JDK 21, Android Studio (or the SDK command-line tools with `platforms;android-36` and
`build-tools;36.0.0`), Node 22+.

```bash
npm run android             # builds the web bundle, syncs it into android/, opens Android Studio
npm run android:apk         # debug APK → android/app/build/outputs/apk/debug/app-debug.apk
```

Release build: `android/keystore.properties` and `android/upload-keystore.jks` are gitignored.
With those present, `cd android && ./gradlew bundleRelease` writes a Play Store bundle to
`android/app/build/outputs/bundle/release/app-release.aab`. Keep the keystore and its password
offline. Play Console will not accept a later upload signed with a different key.

## App icons & splash screens

Source artwork lives in `assets/` (`icon-only.png`, `icon-foreground.png`, `icon-background.png`, `splash.png`).
Regenerate every native size with:

```bash
npm run cap:assets
```

## CI

`.github/workflows/build.yml` runs on every push and pull request:

- **web** — lint, type-check and build the site, uploads `dist/` as an artifact
- **android** — builds a debug APK on Ubuntu, uploads `app-debug.apk`
- **ios** — builds the app for the iOS Simulator on macOS (unsigned) to prove the Xcode project compiles
